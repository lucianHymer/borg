# Team MCP tools: only create_thread, configure_thread, disband_team

The collaborative agent teams feature has exactly 3 team-related MCP tools: create_thread (creates Telegram forum topic via direct HTTP API + registers in threads.json), configure_thread (updates team/role metadata), and disband_team (removes team association from all threads). No clear_team or compact_thread MCP tools — those operations are handled by the /clear_team and /compact_team Telegram commands which queue simple messages. All team MCP tools are available to ALL threads (not master-only). The create_thread tool uses direct Telegram HTTP API (POST to api.telegram.org/bot<token>/createForumTopic) because MCP tools run in queue-processor process while the bot instance lives in telegram-client process (separate processes).

**Related files:** src/mcp-tools.ts, src/session-manager.ts
